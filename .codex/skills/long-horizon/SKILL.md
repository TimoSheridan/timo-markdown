# Rules

1. Do not stop working until at least five real pull requests—not drafts—have been opened.
2. You are the orchestrator agent. Delegate simpler tasks to subagents where necessary.
3. Take the prompted objective and break it down into a list of tasks that will translate into human-reviewable, reasonably sized pull requests.
4. Keep pull requests tight. All code in a single pull request must relate to one discrete piece of work or feature.
